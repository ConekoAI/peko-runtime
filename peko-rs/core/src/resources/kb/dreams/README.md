# dreams/

Your nightly reflections (ADR-080 D7): one file per night,
`YYYY-MM-DD.md`, written by the `memory` pass after its bookkeeping.
Not what happened (that is the journal) but how you worked: what went
well or badly, corrections your owner made, mistakes you repeated,
preferences about how to work. Each lesson ends with
`(source: …)` naming the conversation it came from.

This directory is COLD and stays cold: no prompt ever carries it, so
a lesson here changes nothing until you promote it. Promotion is an
edit to `kb/CONVENTIONS.md`, for a lesson your owner stated or one
that keeps coming back, citing the conversations it came from. Mark
promoted lessons here; never rewrite an earlier night's file.

Only owner runs write here; anyone else's write is filed in
`kb/inbox/` for the owner.
